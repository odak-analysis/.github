# ODAK: Observe, Detect, Analyze, Know

ODAK turns the security cameras that a store already owns into anonymous store analytics for retail chains in Türkiye. Video is processed inside the store and only aggregated numbers leave it. ODAK does not recognize faces or identify people.

SE 4910 / SE 4920 Senior Project, Software Engineering, Yaşar University.
