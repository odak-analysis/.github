# ODAK — Team Rules

This repository keeps the rules that all ODAK repositories share:

- [`CONTRIBUTING.md`](CONTRIBUTING.md): the team agreement for branches, commits, pull requests and reviews.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md): the form that opens with every new pull request.

GitHub applies these files to every repository of the `odak-analysis` organization that does not have its own copy.

The [`profile/`](profile/README.md) folder holds the text shown on the organization page.
